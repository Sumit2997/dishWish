# **App Name**: DishWish

## Core Features:

- Recipe Generation: Generate 5 Indian recipes based on an image or name of a vegetable using the Gemini API. The LLM uses its tool to incorporate estimated cooking time and protein content, as well as related YouTube videos.
- Recipe Display: Display the generated recipes with their estimated cooking time, protein content, and links to related YouTube videos in a user-friendly format.
- Input Handling: Enable users to input a vegetable image or name to trigger recipe generation.

## Style Guidelines:

- Primary color: Earthy green (#388E3C) to represent freshness and natural ingredients, but with a slightly brighter, more inviting tone.
- Secondary color: Warm orange (#FF9800) to evoke the flavors and spices of Indian cuisine, adjusted for higher saturation to be more attractive.
- Accent: Mustard yellow (#FFB300) for highlights and call-to-action buttons, tweaked for better contrast and visual appeal.
- Clean and readable typography for recipe details, with a focus on modern, attractive fonts.
- Use food-related icons to represent different recipe elements, ensuring they are visually appealing and consistent.
- Clean and organized layout to present recipes effectively, with a focus on visual hierarchy and user experience.
